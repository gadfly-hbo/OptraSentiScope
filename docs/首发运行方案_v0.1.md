# OptraSentiScope 首发运行方案 v0.1

确认与固化日期：2026-11-16（Asia/Shanghai）。状态：运行形态及职责边界已获用户确认；未部署、安装或运行验证。

## 1. 依据与确认范围

首发采用**单企业专用常驻环境＋浏览器工作台＋独立计算域**。承接[通用产品首版](通用产品首版范围与完整使用过程_v0.1.md)、[DSH架构v0.2](DSH_技术架构方案_v0.2.md)和[接入方案v0.1](Call只读接入与superagent源码消费方案_v0.1.md)。原始方案、认可及证据身份见[确认记录](首发运行方案_v0.1_确认与证据记录.md)。

已确认的是运行形态与边界。具体机器、地址、维护人、首批来源、隔离载体、凭据系统和网络部署尚未确定，不据此假定任一现有设备或云资源已获使用授权。

## 2. 部署与浏览器入口

优先选择企业控制、资料可达且有人维护的常开Linux主机或虚拟机。主要资料在内网时优先企业内网，主要资料已在企业云时选择对应受控私网。服务承担启动、恢复、备份与故障处理责任，负责人个人笔记本或浏览器的存活不承担持续委托责任。

负责人打开统一工作台地址并完成必要登录，进入委托总览；提醒直达对应事项。关闭页面不暂停委托。Host中断时显示最后可核实状态及服务不可确认，不能继续伪报研究运行。

产品入口通过HTTPS和受信访问控制开放，管理面限制给维护者。SDK原生进程级认证不自动等同企业／委托业务权限。产品接口仍核当前身份和owner，不直接把全权运行管理面作为日常工作台。

不要求SentiScope与Call同机。Call接缝实现后排，Call保留原环境，待受限接缝完成后接入；不挂载Call数据根来顶替新接口。后续实施可先推进Host、工作台、研究及其他获准来源，阶段交付与Call实际接入验收分别记录。该排期不自动删除首版Call必需能力。

## 3. 凭据管理

管理者配置模型、Call、数据库及连接器凭据；Host按需解析。浏览器只持产品登录凭证，Agent获得绑定委托的能力引用，不接收原始密钥，不重复要求负责人登录各系统。

凭据留在受管理Host域，不提供给任意代码环境，不进入提示词、工具结果或诊断日志。正常获准使用不逐次确认；凭据失效交对应管理者处理，不能把环境故障等同新的业务取舍或要求负责人逐项恢复运行资源。

官方本地凭据文件的0600权限约束其他OS用户；同一用户运行的Agent工具仍可能读取。因此，权限位和不主动告知路径不能证明密钥对Agent不可达，必须与所有执行入口的隔离一起落实。[官方凭据说明](https://github.com/deepseek-ai/deepseek-harness/blob/38a6a5c965aa99ab525161efb7cc5cf1fe62fced/packages/credentials/credentials-local/README.md#L113-L115)

## 4. 计算隔离

模型生成代码进入受控容器或计算虚拟机，统一文件、shell、终端和后台作业的执行环境。只提供本委托获准输入、结果目录和资源配额，不挂载Host主目录、密钥、Call数据根或宿主控制socket，不继承密钥环境变量。

计算环境默认无网络；需要资料时，通过获准工具或明确授予的连接能力。Agent与子Agent仍由同一Harness管理；隔离环境不是另一套Agent Runtime，研究方法由Agent自主选择。

优先评估复用官方SSH、文件、进程及沙箱接缝，具体载体和接线方式在后续规格落实。必须覆盖全部执行入口，不能仅隔离Python而让文件工具仍读取Host。

官方SandboxMode只约束文件效果，网络和进程可见性不在该模式承诺内；full／partial也需按实际平台核定，状态名不替代隔离证据。[官方沙箱契约](https://github.com/deepseek-ai/deepseek-harness/blob/38a6a5c965aa99ab525161efb7cc5cf1fe62fced/docs/subsystems/sandbox.md#L5-L30)

## 5. 资料出口

| 出口 | 已确认边界 |
| --- | --- |
| 模型输入 | 仅使用获准端点及获准内容，历史、摘要、工具结果与附件同样受当前资格约束 |
| 外部研究及连接器 | 按研究授权和网络策略开放，内部系统访问与外部采集分别限定 |
| 提醒及人工导出 | 限接收人、渠道及内容范围，默认优先摘要与事项链接 |
| 日志、监控及备份 | 留在企业控制范围，避免密钥和不必要正文进入诊断日志；额外会话日志上传关闭，必要原生历史仍按授权保留 |

部署位置与出口授权分别决定。Host位于企业内网，也需明确哪些资料能进入外部模型。普通获准使用不逐次审批，新增出口或扩大披露范围时由对应负责人决定。

固定rc.3的默认网页抓取可访问私网、loopback和云metadata地址，不能当作仅访问公网的隔离入口；须配置受控工具策略和网络边界。[当前fetch限制](https://github.com/deepseek-ai/deepseek-harness/blob/38a6a5c965aa99ab525161efb7cc5cf1fe62fced/packages/web/web-fetch-http/README.md#L128-L135)
