## 2. 金额和时间口径

- 以确认收货时间归销售季度。平台结算、银行到账刻意设置为不同时间，单独供对账；不把“确认收货”与实际银行到账视为同一事实。
- 商品实付额已经扣除商家优惠；不再扣一次折扣。本例统一采用不含税商品金额，不模拟运费收入、税费或平台补贴。
- 净销售额＝本季度确认收货订单的商品实付额－截至观察时点已生效且已可获知的关联商品退款。
- 退款申请不扣实际净销售额；未完成申请和未给出的处理结果保留未知。退款发生期展示其实际生效季度，不与原订单季度视角相加。
- 每项记录区分业务发生时间和 `available_at`。9月29日发生、10月3日才获知的400元退款，在9月30日初评输入中不可见，后续按资料补到处理。
- 固定考核基期采用2025Q3同一净销售定义、15天观察时点的100,000元；未模拟基期此后的修订。9月30日是未成熟的阶段对比，10月15日才是匹配观察长度的复评；10月22日展示对固定管理基准的最新修订。每次说明观察长度，不能把不同成熟度对比说成最终同比。

## 3. 成本费用归属

以下为本POC管理分析规则，供整体确认；不替代企业正式财务核算。

| 类别 | 候选归属 | 去重与跨期规则 |
| --- | --- | --- |
| 商品成本 | 商品毛利层。采用原订单对应的单件成本版本，已含每件3元入库运输 | 不再将这笔入库运输列入履约费用；新版本不静默替换旧来源 |
| 退货成本回转 | 本例实物已退回且确认收到，回转对应商品销售成本 | 仅退款不回转；退回后已回转成本的残损另列货损 |
| 平台与支付费用 | 经营贡献层。佣金2%，支付手续费0.6% | 佣金按实际返佣记录抵减；支付手续费本例不返还，不能由退款推定所有费用恢复 |
| 物流履约 | 经营贡献层。正向每单5元，实物逆向每件8元 | 关联原订单季度，同时保留发生期；不与商品成本内运输重复 |
| 售后损耗 | 经营贡献层。两件退回衬衫已回转成本，再确认货损300元 | 仅退款商品未回转的原成本已在商品成本内，不再另扣同额货损 |
| 营销费用 | 经营贡献层及营销预算。广告、内容制作按实际服务消耗归季 | 付款时间另列；同合同已消耗部分从未消耗承诺中扣除；商品优惠、交易扣点不再混作本例营销费用 |

商品毛利＝净销售－（原商品销售成本－已确认回转成本）。整体毛利率＝合计商品毛利／合计净销售，不平均SKU毛利率。

本POC经营贡献＝商品毛利－净交易费用－正逆向履约－独立售后货损－实际营销消耗。已承诺未消耗金额只占预算，不再次扣当期经营贡献。本例没有跨店共同费用；未来引入时再约定分摊。

营销实际消耗19,000元；其中6,000元内容制作于9月25日验收、10月10日付款，仍归Q3消耗。另有2,000元达人排期未履约且未获解除确认，继续占用预算。预算占用21,000元，超上限3,000元；其中实际消耗本身已超1,000元。

## 4. 季末初评、15天复评与晚到修订

- 9月30日初评：固定当时可知资料，说明退款尾部与数据延迟，不宣称最终达成。
- 10月15日复评：纳入观察期内可知的退款和补到资料。650元未完成申请继续单列，不当作已退款，也不编造预计最终净销售额。
- 合成剧情中10月16日的管理确认：窗口已到、对账可核，未决申请最大影响已说明，保留该版供管理比较；仍不代表退款永不再发生。
- 10月20日发生晚到质量售后补偿，10月22日形成最新回溯版。冻结版不覆盖，需说明净销售、毛利及判断变化。
- 重大修订候选标准：任一目标约束状态翻转，或净销售修订绝对值达到目标2%，或毛利率变动至少1个百分点。列为重大修订不自动等于立即打扰；即时提醒还检查当前决策窗口。
- 本例10月23日存在下一阶段投放／供给取舍窗口，晚到退款改变毛利底线判断，应及时提示负责人；是否重开考核仍待负责人决定，Agent不代作决定。

## 5. Call 的最小上下文积累

[Call合成上下文](inputs/call-context.json)提供净销售、毛利、预算三项口径，目标RAP、一个有适用条件的基期Case，以及一条未核验候选认识。`poc_assumed_published` 等状态只是本包虚拟前提，不表示真实Call已发布资产或已通过验收。

准备充分性核验关注：能否找准目标与版本、核对经营数字、使用背景、限制旧经验、接受新证据修正，并保留关键未知。当前资料包括库存快照和补货计划，但没有完整库存账或实际补货验收；不能凭计划认定已到货，也不能仅据快照确定销量变化的因果。

## 6. 后续POC应观察的行为

- 从目标和资料自主识别问题、风险与机会，研究方向不预先固定。
- 识别季末净销售初步达到目标，同时保留预算异常和退款成熟度限制。
- 复评时解释数字变化及来源：既包含晚获知的原季退款，也包含新发生退款。
- 按新证据修正长裤投放经验与“退款成本手续费都会恢复”的候选认识；不把旧记忆或多数Agent说法当证据。
- 处理仅退款、可再售退货和残损，保持成本费用只扣一次。
- 分清方案、负责人选择和执行；未采纳建议不生成虚假执行效果。
- 对晚到退款更新最新判断，保留已确认管理版及原FAIL/UNKNOWN；重大变化按决策窗口决定提醒方式。

这些是覆盖范围，不是唯一研究路线或措辞答案。合理的不同方法、解释和方案可接受，但关键数字、来源、边界和未知应能核对。
