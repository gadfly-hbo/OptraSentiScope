## 起点与结果

仓库交付基线为 `6a01fd1`，P03–P05 回执记录的本机运行版本为 `44760bd`。上次浏览器演练已跑通“建委托 → 来源更新 → 暂停、恢复 → 重开读回”，但在建委托之后有一步由维护者绑定合成来源并重开服务。默认合成预算面向一小时短演练，插件激活失败也可能只留下 warning。Qoder 先在现有正常入口复核这些事实，按实测修复阻塞；已满足的条目用证据关闭。[上轮切换与演练](../openspec/changes/p03-p05-sustained-sources/results.md#试用实例切换)

本轮有两份交付。主线交付经营者可以亲自验收的本机合成试用体验。并行工作交付未来评阅者可以独立使用的案例包与判定规则。二者分别记结果，真实模型质量和完整 AC07 继续待验。

## 主线验收清单

| 验收项 | 实际操作与可观察结果 |
| --- | --- |
| 一次配置，独立建委托 | 维护者在授权范围内一次配置可用的合成来源。经营者以普通角色登录，用一句话新建符合条件的委托，看到可用来源和首个有依据的进展。记录全过程中的人工动作；建委托后无需维护者逐单绑定、改配置、重启服务或手工触发研究。 |
| 持续跟进与持久读回 | 合成来源由测试方按预设顺序更新，经营者能看懂变化、判断及其依据。暂停受影响的研究，恢复后自动核对期间变化；关闭并重新打开工作台可读回同一委托与进展。另在隔离环境验证服务重启后的持久记录。 |
| 委托之间权限独立 | 用两个授权范围不同的委托检验共享来源：不符合预设资格的委托建成后不能自动获权。单方撤权后新读取和历史正文回放受限，另一方继续工作。来源失联时显示最近可核实状态、影响范围和补读条件。浏览器只取得当前角色允许的内容。 |
| 停止原因与恢复条件可见 | 实测预算到期和运行插件未就绪。经营者能区分等待资料、预算用尽和服务不可用，知道哪些工作受影响、由谁处理、什么条件下可继续。用实际资源和调用状态核实，保留限额、取消、UNKNOWN 和历史回执，禁止静默续费或重放。故障演练使用隔离配置。 |

沿用现有 Host、官方运行时、合成 Provider 和计算 OFF。Host 核对资格与资源，Agent 自主决定研究方法。新增或实质调整关键交互时，Qoder 提交差异规格与可点击 Demo，用户确认后实施相关 UI。工程演练和经营者本人最终的体验结论分别记录。

## 并行准备的研究判断案例

- **案例输入。** 用同一组虚构资料编一项初始委托，按时间释放初始事实、新证据、反证，再提供后续委托以覆盖经验适用和不适用两种条件。给资料稳定的 ID、版本和可知时间，使评阅者可以复原每个时点能看到的证据。可复用已有合成资料。经营者可见输入、分批释放安排、仅供评阅的参考依据分开保存。
- **评阅规则。** 对准确引用、原判断的保留／修正／撤回、依赖建议的逐项重评、经验在后续委托的采用／拒用、旧版本和未知保留逐项定义“符合／不符合／证据不足／未运行”。列出可观察证据和典型失败，例如用后到资料解释先前判断，或出现反证后仍照搬一条已失效的建议。允许多种合理结论，以证据和适用边界判定。
- **材料验收。** 交付固定版本的输入、释放顺序、评阅表和一页使用说明。请非作者根据材料离线检查引用可还原、反证能区分不同表现、参考依据对被评 Agent 不可见。为将来记录模型配置、耗时、用量与可核费用预留位置；本轮真实模型运行及评分均记为未运行。[AC07 原始验收口径](通用首版搭建规格_v0.1.md#8-后续工程批次与验收)

## 交回与后续决定

Qoder 将两条工作写入本轮 OpenSpec，负责实施、回归、非作者独立复核及有效授权内的 Git／CI 和本机试用交付。交回固定候选、实际验收环境与版本、经营者体验步骤和证据、案例包与评阅表，以及失败和未验项。用户负责经营者体验验收。本轮不接真实来源、不调用真实模型；后续模型端点、允许发送的内容、预算及具体来源由用户另行确认。Call 接入继续后置。
