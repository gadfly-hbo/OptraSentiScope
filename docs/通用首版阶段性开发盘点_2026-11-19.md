## 与 11-17 盘点的差异

- 跨来源 epoch 普通 judgment/plan 的主 Agent exact read 从“拒绝”修正为“完整重验后可读原正文”；metadata 投影仍不回放正文，失权/缺失返回安全状态与 UNKNOWN。
- 支持关系允许显式 judgment→judgment、judgment→plan，并按完整路径生成重评责任；普通引用和共享资料不连边。
- 同一建议事项 P1→P2 可用准确新 plan 版本和关系修订 CAS 合法调整；迟到或并发结果不能关闭当前责任。
- 支持关系请求重放兼容规范化摘要与旧历史 hash，重复请求返回原回执。
- 官方自然唤醒路径不再用替身 wake、`coordinator.sync` 或手动 schedule run 代替正常 recurring Schedule 到期。
- 新增条件经验闭环、结构化 intake、方向级生命周期控制、简报偏好、备份/校验/恢复。
- `SourceStore.listReferences` 仅返回当前 enabled 且 ready/unavailable 的引用；revoked 不再是当前引用。
- artifact-followup 官方检查的撤权断言改为读取官方 session 历史中的真实 tool error；不改产品语义。
