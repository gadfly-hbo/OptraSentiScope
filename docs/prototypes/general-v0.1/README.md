# 通用首版关键交互 Demo v0.1

状态：**UI 候选，待用户确认**。这是可丢弃的静态交互原型，不是产品实现或首版完成证明。

直接打开本目录 [index.html](index.html) 即可使用，支持 `file://`。如需静态预览，从仓库根目录执行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/prototypes/general-v0.1
```

然后打开 `http://127.0.0.1:8765`。无需安装依赖。

建议试用路径：

1. 总览点击「新建委托」，填写非空自然目标，一次创建即进入「进展」；可选填写边界。观察总览提醒与委托列表。
2. 在委托内切换「方案与依据」「待决事项」「结果与学习」「资料」「补充对话」，展开依据原文与版本，试用亮暗切换与窄屏。
3. 在待决事项先「知悉」，确认仍待决；再采纳、暂缓或提出调整，观察版本绑定与独立选择记录。采纳不会更新执行、观察或归因。
4. 展开独立的「演示情境」，模拟新信息、独立问题及重复投递。新信息更新原研究，独立问题另建；重复投递不重复建单。离开详情再返回，变化仍在本页内存中。
5. 在未采纳时也可直接模拟执行反馈；再模拟结果变化，观察选择仍独立、归因保持 UNKNOWN；连续模拟反证，观察经验受限、撤回与原判断保留。
6. 调整委托生成新版本；暂停先显示「正在暂停 / 停止中」，点击明确的「模拟停止回执」才进入「已暂停」。恢复先核对资格，再点击「模拟恢复资格回执」。失联与撤权只影响依赖来源的部分。
7. 结束委托后模拟停止回执，检查待决收束为未选择、成果保留；再投递新信息，确认不会重开。可新建关联委托。
8. 演示情境提供观察等待、来源失联/撤权、技术故障/UNKNOWN、清空空态与全部重置。直接失联来源 A，可观察依赖部分受阻、初始来源 B 的独立研究保留。

页脚可按需展开「运行与资料边界（设计说明）」：查看正式产品的常驻运行计划、Host 与 Agent 分工，以及模型输入、外部研究与连接器、提醒导出、日志监控备份四类资料出口边界。该说明不是实际控制已实现的证明，也不增加业务操作。恢复核对期间，研究问题显示「待恢复资格核对」，模拟恢复回执后才按当前资格与 UNKNOWN 状态呈现续作情况。

所有示例名称、原文、引用、版本和演示时钟均为虚构。Call 始终「待接入」，未读取 Call；未连接模型、SDK、企业来源、文件或网络 API。没有真实上传、账号、授权、经营执行、资源隔离或故障恢复。研究状态只是显式操作产生的演示投影，不能证明真实 Agent 已研究。

所有输入仅在页面内存；没有 localStorage、服务端或持久化。刷新/关闭后状态丢失，关闭页面后不会继续工作。页面内切换保留状态，不能替代真实页面关闭后持续运行验证。模拟停止与恢复回执不证明实际资源停止、权限隔离或恢复完成。
