运行与资料边界（设计说明）

正式产品计划：由常驻 Host（运行环境）持续承接委托，浏览器只提供工作台，不承担持续运行责任。资源、凭据与隔离由 Host 维护；Agent 在获准范围内自主选择研究方法。

以下是尚未实现或验证的资料出口约束，按企业及委托的授权范围执行：

模型输入
只向获准模型发送获准内容，相关历史、摘要、结果与附件也受同一范围约束。
外部研究与连接器
按获准来源和网络范围开放；内部资料访问与外部研究分别限定。
提醒与导出
限定接收人、渠道和内容，默认优先摘要与事项链接。
日志、监控与备份
保留在企业控制范围，避免凭据和不必要正文进入日志；额外会话日志上传关闭。
